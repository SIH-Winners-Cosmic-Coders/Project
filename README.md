### 🚀 Quick Evaluation Setup (2 Steps)

#### Step 1: Start the Backend
1. Double-click `run_app.bat`.
2. The local server will start and automatically open the application interface.

#### Step 2: Load the Chromium Extension
1. Open Google Chrome or Microsoft Edge and navigate to `chrome://extensions/`.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked** in the top-left corner.
4. Select the `agri-care_Web` project folder.
5. Click the **AnnaDATA** leaf icon in your browser extension toolbar to open and test the application at any time.
